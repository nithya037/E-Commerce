# Nostra – E-commerce Website

A modern, responsive e-commerce website designed to provide a clean, elegant, and user-friendly shopping experience. Nostra focuses on everyday fashion, lifestyle products, and thoughtfully selected collections.

## ✨ Project Overview

**Nostra** is a frontend e-commerce website developed using HTML, CSS, and JavaScript. It features a responsive layout, interactive navigation, product collections, search functionality, product filtering, sorting, and favourite products.

## 🚀 Features

### 1. Home Page
- Responsive navigation bar.
- Announcement banner with close functionality.
- Hero image slider with navigation controls.
- New Arrivals section.
- Most Wanted product carousel.
- Favourite products using heart icons.
- Responsive footer.

### 2. Collections Page
- Product search functionality.
- Filter products by occasion.
- Filter products by color.
- Filter products by category.
- Price range filtering.
- Sort products by price and name.
- Dynamic product count.
- Clear All filter option.
- Favourite products with red heart animation/state.
- Local Storage to save favourite products.
- Empty search result message.

### 3. Contact Page
- Contact information section.
- Contact form.
- Responsive page layout.

## ⚙️ How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript, and image files are in their correct locations.
4. Install the Live Server extension in VS Code.
5. Open `index.html`.
6. Right-click and select **Open with Live Server**.

The website will open in your default browser.
